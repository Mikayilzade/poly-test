# Visual / UI reference plan

The goal is not to archive the whole game package. It is to catalogue public visual evidence that helps reproduce layout, state feedback and cosmetics.

## First-party/public sources

- Official Steam screenshots: https://store.steampowered.com/app/874390/The_Battle_of_Polytopia/ [STEAM-BASE]
- Official game graphics catalogue: https://polytopia.io/game-graphics/ [OFF-GRAPHICS]
- Official Path of the Ocean illustrations: https://polytopia.io/path-of-the-ocean/ [OFF-OCEAN]
- Official Diplomacy illustrations: https://polytopia.io/diplomacy/ [OFF-DIP]

## Screens to inventory

- main menu
- tribe picker + skin picker
- game setup / map type / size / bot difficulty
- in-game HUD (score, stars, turn, tech, end turn)
- tile/unit selection panels
- city panel and upgrade modal
- technology tree
- diplomacy / tribe relations
- multiplayer setup
- replay/spectator UI
- victory/defeat/score screens
- tutorial/Boot Camp
- settings and accessibility/localization surfaces

For every screenshot we later save or reference, record: source URL, date/version if known, platform, screen/state, and what mechanic/UI detail it proves.

Midjiwan publishes a Game Graphics page and a Brand/Asset Usage Guidelines page. The latter says they are relaxed about things created privately and permits certain non-commercial community uses while restricting distribution of game assets; this repo therefore defaults to links/metadata unless the specific published asset is clearly offered for reuse. [OFF-GRAPHICS, OFF-ASSET-GUIDE]
